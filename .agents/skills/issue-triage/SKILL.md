# Issue triage

- Fetch the issue with the jira tool before saying anything about it.
- Judge against the project's workflow states and their exit criteria.
- Report: missing fields, unaddressed comments, likely duplicates, stale work.
- Be terse; list concrete gaps, not generalities.
